# Claude Fan Art Bot

An all-in-one helper for creative communities: ideas to make, levels to earn, and tools to keep your community friendly and safe. 🎨

## ✨ Creative prompts
- **/prompt**: a random drawing idea
- **/prompt game**: a game idea (genre, mechanic and twist) for game jams
- **/prompt video**: an animation or video idea
- **/palette** and **/colors**: colour palettes and colour challenges
- **/trade**: pairs members up for art trades

## ⭐ Levels and rewards
- Earn XP for chatting, and **double XP for sharing art**
- **/daily** bonus with streak rewards
- **/level**, **/profile** and **/leaderboard**
- Automatic level roles: create roles named "Level 5", "Level 10" and so on

## 🎉 Community fun
- **Giveaways**: react to enter, winners picked automatically
- **/poll**, **/8ball**, **/coinflip**, **/roll** and **/remind**
- Friendly welcome messages for new members

## 🛡️ Moderation and support
- **/warn**, **/kick**, **/ban** and **/purge**, with a private mod log
- **Tickets**: members open a private channel with the mods using **/ticket**
- **/rules** and **/postrules** to post and pin your rules

Type **/help** to see every command. Moderators can type **/modhelp**.
