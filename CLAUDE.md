# Always-on skills

Use these project skills automatically (invoke them with the Skill tool) without waiting to be asked:

- **lean-code** — on every coding task: write minimal code, then run its cleanup pass on your diff before finishing.
- **idea-research** — at the start of every new build request (feature, mechanic, scene, UI, tool). If the user already said to build it, research briefly and then build instead of stopping to ask.
- **modern-lua** — whenever writing or editing any `.lua` / `.luau` file or Roblox script.
- **blender-3d-models** — whenever a 3D game needs a model or asset; build it in Blender instead of using placeholder shapes.

Skip a skill only when the task clearly doesn't fit it (e.g. a one-line fix doesn't need idea-research).
